# Niko Clicker

Кликер с Нико из OneShot. Сидит на рабочем столе, кликается, отвечает на команды, ловит панкейки.

## Запуск

Скачай `NikoClicker.exe` из [Releases](../../releases), положи на рабочий стол, запусти.



## Из исходников

Нужен Python. Потом в терминале:

    pip install pygame pillow
    python main_old.py

## Управление

- ЛКМ — клик
- ПКМ + тащить — переместить
- ПКМ дважды — закрыть
- Поле внизу — команды

## Команды

`привет`, `как дела`, `пока`, `спасибо`, `кто ты`, `скучно`, `люблю`, `мяу`, `панкейк`

`выключи пк`, `перезагрузка`, `отмена`  работают на (Windows).

## Прочее

Фан-проект. Спрайты Нико принадлежат разработчикам OneShot.
